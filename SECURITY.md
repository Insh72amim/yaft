# Security Policy

YAFT (Yet Another Finance Tracker) handles sensitive personal financial data. We take security and privacy seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in YAFT, please report it privately. **Do not create public GitHub issues or discussions for sensitive security bugs.**

### How to Report

1. **GitHub Security Advisory (Preferred)**:
   Navigate to the [Security Advisories](https://github.com/Insh72amim/yaft/security/advisories/new) tab of the repository and click **"Report a vulnerability"**.

2. **Email**:
   If you cannot use GitHub Advisories, email the maintainer privately at:
   `security@yaft.in`

### What to Include

- Description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any affected components (e.g. statement parser, credential vault, authentication middleware).

> **Important**: Never include real financial records, passwords, account numbers, or bank statement PDFs in your vulnerability reports. Use synthetic/anonymized samples only.

## Disclosure Policy

- We will acknowledge receipt of your report within 48 hours.
- We will coordinate a fix and release an update as quickly as possible.
- Once a fix is released, we will publicly credit reporters who followed responsible disclosure guidelines.
