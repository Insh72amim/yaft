Core Capabilities

Built with Institutional Rigor.
Designed for Absolute Clarity.

YAFT combines the precision of high-frequency accounting systems with the tranquil, focused user experience of modern personal software.

⚖️
Zero Floating-Point Drift

Signed Integer Minor-Unit Math

Financial software must not suffer from IEEE 754 float imprecision (0.1 + 0.2 ≠ 0.3). Every single currency calculation in YAFT is computed in exact integer minor units (paise) down to the last decimal.

✓ BigInt paise precision across all DB models
🛡️
Never Hallucinates Missing Numbers

Fail-Closed Statement Parsers

If a bank statement or corporate payslip is unreadable, ambiguous, or fails balance equations (Opening + Inflows - Outflows = Closing), YAFT fails closed immediately rather than corrupting your ledger.

✓ Strict running-balance verification guarantee

SaaS financial aggregators harvest your spending habits, monetize merchant graphs, and store raw financial statements on multi-tenant cloud servers. YAFT eliminates the middleman entirely.

Zero Cloud Telemetry

YAFT never communicates with external tracking servers, third-party LLM endpoints, or advertising networks. Your entire financial history lives strictly on your local machine or private home server.

👤🔒

Single-Owner Instance Lock

The moment you create your administrator account on initial setup, YAFT permanently locks public registration. No unauthorized guest accounts can ever be spawned on your private instance.

AES-256-GCM Credential Vault

Bank statement passwords, card CVVs, and sensitive document keys are stored encrypted on disk using AES-256-GCM with unique Initialization Vectors (IVs) and authenticated tags.

💾📦

Local MinIO S3 Storage

Uploaded PDF bank statements, corporate salary slips, and account proof documents are stored in a self-hosted MinIO object storage container — isolated from the public internet.

🔐⚡

Argon2id Password Security

User authentication uses memory-hard Argon2id hashing with HTTP-only, SameSite session cookies to safeguard against offline brute-force and token hijacking attacks.

🗄️✨

1-Click Encrypted Backups

Export your entire instance — PostgreSQL ledger tables, categorization rules, dynamic parser configs, and MinIO document storage — into an encrypted .yaft-backup archive in seconds.

Frequently Asked
Questions

Everything you need to know about YAFT architecture, security, and statement parsing.

Financial records contain your most sensitive personal information: salary, bank account balances, tax deductions, medical expenses, and daily whereabouts. Cloud finance apps monetize this data, train models on your habits, or shut down unexpectedly (like Mint). YAFT runs strictly on your own hardware, guaranteeing zero third-party cloud data harvesting.

YAFT includes native fail-closed PDF parsers for Axis Bank, State Bank of India (SBI), Punjab National Bank (PNB), and EPFO Passbooks. It also imports Zerodha Kite and Groww portfolio snapshot sheets, plus real-time credit card swipe alert sync for HDFC Bank, ICICI Bank, Axis Bank, and SBI Card via the Gmail API.

YAFT connects directly to the official Google Workspace / Gmail API using client-controlled OAuth2 tokens. Your credentials remain in your local PostgreSQL database. The worker fetches only credit card transaction alert emails, parses the merchant and amount, and matches them to your pre-existing accounts without spawning extraneous accounts.

Instead of requiring custom code changes for every employer, YAFT provides a dynamic JSON parsing engine (parsingConfig). You can configure regex anchors for Gross Earnings, Deductions (TDS, PF, Professional Tax), and Net Pay, test them in a visual equation sandbox (Gross - Deductions = Net Pay), and decrypt password-protected PDFs on the fly in RAM using qpdf.

Standard JavaScript numbers use IEEE 754 floating-point math, where 0.1 + 0.2 equals 0.30000000000000004. In accounting, this creates balance drifts. YAFT stores and calculates all balances and transactions as signed integer minor units (BigInt paise), ensuring 100% exact balance arithmetic down to the paisa.

Yes! YAFT is fully containerized with Docker Compose. It runs smoothly on any Linux, macOS, or Windows machine, including Raspberry Pi 4/5, Synology NAS, Unraid, TrueNAS, or home server environments.

YAFT features a 1-click backup and restore engine under Settings (/me). It packages all PostgreSQL database rows and MinIO S3 statement PDFs into an encrypted .yaft-backup archive file that you can restore to any new machine or container in seconds.
